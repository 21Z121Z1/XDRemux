# 原生响应与校准实验方法

[English](methodology.en.md) | 简体中文

本文保存历史求解器实验的方法和限制，不代表已经复现私有实验，也不定义第二套转换器。公开模型身份及其历史测量见[模型卡](models/UniversalPhotographicStyleStateNet.model-card.md)。

先前的收敛台账不在当前目录树中。涉及已退役引用的主张仍需原台账和源文件身份；本文不能替代这些证据。

## 隔离数据队列

历史原生数据集包含 603 个样本，来自 472 个拍摄会话。训练集、校准集和留出集分别包含 417、89、97 个样本。这些是样本数，不是会话数。历史记录称集合按会话隔离，但私有清单和源文件字节不在 Git 中。

原生响应队列在各既有集合和设备组内，选择源 SHA-256 字典序最小的样本，不查看图像质量或指标。报告覆盖四种设备，每种设备各取一个校准会话和另一个留出会话。

重新实验时，对实际字节计算哈希，拒绝缺失文件、重复身份和跨集合重叠会话。在新的不可覆盖清单中记录数据集、模型、检查点、代码和系统身份。旧选择器直接信任清单哈希并覆盖目标，不能据此完成可复现的身份核验。

前瞻 OPPO 队列排除了四个历史 A/B 场景，以及早期审计出现过的全部 SHA-256，然后按源哈希为每个设备组选取一张可用图像。历史报告包含五种设备。清单此前已被无标签查看过，因此「前瞻消费者队列」不等于从未见过的图像分布。

必须同时排除场景身份和字节身份，记录此前接触清单的情况。不能在查看模型响应后重选图像。路径存在不代表文件内容符合记录的哈希。

历史 A/B 场景参与过模型和尺度选择，因此标为 **unlocked**。分布外试验使用校准集 p95 不确定度作为接受阈值，只测量覆盖率，不测量原生渲染精度。DNG 预览不是解码后的 RAW 观测。

当前 [training.py](training.py) 和 [inference.py](inference.py) 要求提供已解码的可选输入，并核验字节身份，不通过文件扩展名或标记字符串推断输入可用性。

## 固定响应矩阵

历史矩阵包含八个状态：

| 状态 | 用途 |
| --- | --- |
| `disabled` | 关闭风格的参考状态。 |
| `neutral` | 中性风格参考状态。 |
| `tone_+1` | Tone 正端点。 |
| `tone_-1` | Tone 负端点。 |
| `color_+1` | Color 正端点。 |
| `color_-1` | Color 负端点。 |
| `tc100_mid` | 历史组合控制状态。 |
| `tc100_plus` | 历史组合控制状态。 |

渲染前固定完整矩阵。保存原始载体、候选载体、请求、实际返回的像素，以及源文件、候选、模型和检查点哈希。记录框架、系统、命令、退出状态和错误。

完整 Styles 资源图、有限值代理响应和原生渲染器响应属于不同证据。色彩空间、方向、尺寸和位深解释必须固定，不能静默转换不兼容的像素表示。

历史 alpha 网格为 `[0, .25, .5, .625, .75, 1]`，基线为 `.625`。拟比较的残差增益为 `[.5, .75, 1, 1.25, 1.5]`。校准集只在全部条件满足时选择候选：

- 改善至少 1%。
- 任一设备退化不超过 10%。
- 缺失响应、失败响应和方向反转均不增加。
- 所有要求的状态和队列均已得到结果。

评分是各状态编码 RGB 域 RMSE 的平均值，不是汇总后的线性光误差。

## 报告必须保留失败

旧 alpha 汇总器即使选中其他 alpha，也可能把留出集基线缓存标为 `chosenAlpha`。它还会对不完整状态取平均值，并尝试多个文件名回退。另一汇总器可能在 Markdown 中声称校准完整，而 JSON 报告不完整。这些报告生成器已退役。

缺失的候选或状态必须继续标为缺失。候选测量必须来自该候选，不能来自基线缓存。先保存所选参数及来源，再评估留出集。机器可读结果和正文必须报告同一结论。

无缓存对照比较 alpha 0、.625 和 1，使用不同 Key 1 输入及载体，并分别提交 `neutral`、`tone_plus` 请求和输出。相同像素可能表明消费者忽略了某项变化，不能强制要求输出哈希不同。

不同文件名也不能证明请求或执行不同。必须核对从请求到载体的完整哈希关系，并保留渲染输出身份。原生渲染器不可用时，不能用单位映射输出或语义代理代替。

Issue #32 的历史记录描述了 macOS 27.0 `26A5416b`、Xcode 27 `27A5218g` 上的私有 ABI 变化。旧 `PLPhotoEditSource` 初始化方法移除了一个图像参数；`_NUStyleTransferApplyProcessor` 在色彩空间参数前增加了位移参数。这些已退役 Swift 调用方不属于当前 Rust 产品或窄适配器。

本地实验调用私有方法前，先检查并验证准确签名。超时、缺少选择器或 ABI 不匹配均属于阻塞证据，不是成功的单位映射回退。当前研究 CI 另由 [research.yml](../../.github/workflows/research.yml) 定义，其中包含固定来源的 Tone 响应实验。本文历史记录不为这些运行提供验证结论。

## 应用冻结校正

[calibration.py](calibration.py) 保留了 `evaluate_selfpair_lowdim_adapter.py` 中有效的约束。它拟合三十个归一化多项式项与输出通道偏置，在所有空间位置和分平面间共享。拟合只使用有效观测块，并要求岭正则化系数为正。

应用阶段只使用已保存的系数，接口不接收目标值或掩码。拟合和应用都不修改输入，并检查数值有限性、数组形状、正尺度、大小上限和算术溢出。

在指定训练队列上拟合：

```python
from research.oppo_styles.calibration import ChannelBias, fit_channel_bias, apply_channel_bias

fitted = fit_channel_bias(train_prediction, train_target, train_mask, scales, ridge=10.0)
frozen_record = fitted.to_dict()
```

将保存的记录与代码、队列和模型哈希绑定。校准集只用于选择，不重新拟合这些系数。记录选择结果后，恢复系数并应用到留出集：

```python
restored = ChannelBias.from_dict(frozen_record)
heldout_prediction = apply_channel_bias(heldout_base_prediction, scales, restored)
```

旧脚本虽然保存偏置，却在留出集的 channel-ridge 分支忽略保存值。该分支读取留出标签并重新拟合，违背自身注释。维护中的应用接口无法接收这些标签。

测试在拟合后修改标签、改变空间和分平面尺寸、恢复保存系数，并拒绝非有限值或溢出输入。这些测试证明冻结系数约束，不证明原生精度。

## 区分候选模型与实际拟合

其他历史模型族仍属于研究假设：

| 模型族 | 记录的搜索范围 |
| --- | --- |
| Alpha 混合 | 步长为 .05。 |
| 全局校正 | 残差增益 .85 至 1.15，归一化偏置 −.02 至 .02。 |
| 条件混合 | 按设备、配置或亮度混合。 |
| 共享校正 | 共享偏置或通道偏置。 |
| 设备校正 | 单个偏置参数，岭系数为 1/3/10/30/100/300。 |
| 会话残差 PCA | 秩为 1/2/3，使用 RGB 均值和标准差，岭系数为 100。 |
| kNN | 邻居数为 3/5，收缩系数为 .25/.5/1。 |

训练会话提供拟合数据，校准集选择模型族并决定是否晋级。未知设备配置固定回退到 `.625`。历史自助法按拍摄会话聚类抽样，共 20,000 次，随机种子为 260819。此类置信区间不能把各像素当作独立样本。留出集既不能拟合系数，也不能选择模型族。

17 Pro 脚本会无条件输出拒绝字符串。名为「30-parameter term/channel gain」的候选实际是单位映射，其「bias」只使用一个标量。部分配置恢复流程仅实现按设备选择 alpha。这些名称不能证明所声明的模型族确实完成正确拟合和评估。

重新实现估计器时，必须提供准确的数学实现、明确的拟合状态、源文件顺序和会话检查，以及实际执行的晋级规则。硬编码结论不能作为验收证据。

## 解释训练与导出尝试

维护中的训练包通过 `TrainingInputMode` 区分成对输入和单图自配对。自配对只改变观测，不改变原生目标或缓存字节。

历史 heads-only 实验以很小的学习率，组合真实配对与自配对的 Huber 损失，以及脱离梯度的真实预测一致性目标。它使用宽松的检查点加载，并复用没有保护的输出目录。对应的检查点和报告包装脚本已退役。重新实验需要核验来源、限制反序列化、使用新目录、检查优化过程的有限性、固定集合，并由校准集选择检查点。

| 历史尝试 | 记录的留出集归一化 MAE | 对照 |
| --- | ---: | --- |
| 短程自配对候选 1 | .80226 | 差于自配对基线 .78220。 |
| 短程自配对候选 2 | .78751 | 差于自配对基线 .78220。 |
| 通用模型后接冻结的成对模型 | .82674 | 差于独立通用模型 .82233。 |

两个短程自配对候选均未晋级。级联方案使用通用模型预测的无风格缩略图，对照程序使用真实原生 disabled 缩略图，两者输入不同。使用真实目标图的对照精度不是运行时能力。这些数值属于私有历史测量，不是新的 CI 结果。

旧 Core ML 比较允许 Key 1 和光照图误差 .02、GTC 字节值误差最多 2、标量误差 .1。复现需要准确的检查点、归一化方式、布局、源字节、Core ML 包、计算配置和方向相关序列化。模型包本身不包含这些私有输入。

当前 [CoreMLProbe.swift](CoreMLProbe.swift) 只编译公开模型包，以合成输入执行预测，并检查有限值和形状。它使用 `.cpuOnly`，不证明与 Python 输出或原生渲染器等价，也不证明 Neural Engine 分配情况。

## 接入产品的要求

研究结果必须固定身份和集合，提供完整响应矩阵，且没有隐藏回退或标签泄漏。对照必须包含有意义的单位映射、打乱标签、成对输入和消融情况。设备限制和依赖源数据的资源必须明确且可复现。

接入产品还必须使用现有 Rust 意图、能力和发布模块。元数据角色必须正确，并通过原生消费者验证。声称 Photos 可编辑时，必须提供实际导入、编辑、保存和重新打开的证据。保留的假设不能直接视为产品缺陷或已交付功能。
