# XDRemux v1.4

## English

XDRemux v1.4 is the final release that ships both the Swift and Python implementations.

This release adds Android Motion Photo → Apple Live Photo conversion, improves Photographic Styles, adds asset-aware photo classification, and hardens the conversion pipeline.

Development after v1.4 will move to the Rust rewrite.

### Motion Photo → Live Photo

XDRemux can now convert supported Android Motion Photos to Apple Live Photo.

The output is an HEIC + MOV pair. The conversion preserves the source Motion Photo.

For supported inputs, XDRemux preserves:

- the HDR still image and Gain Map;
- the source cover-frame PTS;
- Apple `still-image-time`;
- compressed video samples;
- compressed audio samples when present.

Motion Photo detection is automatic for supported JPEG and HEIC/HEIF files.

Batch conversion also supports Motion Photos.

The Swift CLI can also combine Motion Photo conversion with Photographic Styles.

### Python implementation

`xdremux-py` is now an installable Python package.

It supports standard HDR conversion, photo classification, and Motion Photo → Live Photo conversion.

The Live Photo implementation does not require Apple frameworks at runtime. It can run on non-macOS systems.

The repository tests the Python-generated Live Photos with PhotoKit on macOS.

### Photographic Styles

Photographic Styles conversion is now part of the normal Swift CLI product path on supported macOS systems.

The implementation preserves the source HDR image and Gain Map while synthesizing Apple-compatible Photographic Styles metadata and auxiliary resources.

The style solver includes global tone-curve fitting, scene-aware policy, semantic mattes, and validation against Apple framework consumers.

### Classification and categorization

XDRemux can classify supported photos by source traits and primary capture mode, and can organize batch results by those classifications.

### Reliability

This release adds stronger structural validation, fail-closed parsing, atomic publication, bounded batch concurrency, checkpoint/resume support, and more real-device fixtures.

### Transition to Rust

v1.4 is the compatibility release for the existing Swift and Python product implementations. The next development line replaces those parallel implementations with one cross-platform Rust CLI and one Rust business core. Apple-only framework access remains behind a narrow platform adapter.

## 中文

XDRemux v1.4 是最后一个同时发布 Swift 和 Python 两套实现的版本。

本版本加入 Android Motion Photo → Apple Live Photo 转换，改进摄影风格支持，加入面向照片资产的分类能力，并进一步加固转换流程。

v1.4 之后的开发将转向 Rust 重写。

### Motion Photo → Live Photo

XDRemux 现在可以把支持的 Android Motion Photo 转换为 Apple Live Photo。

输出为 HEIC + MOV 文件对。转换不会修改源 Motion Photo。

对支持的输入，XDRemux 会保留：

- HDR 静态照片与 Gain Map；
- 原始封面帧 PTS；
- Apple `still-image-time`；
- 压缩视频样本；
- 存在时的压缩音频样本。

对于支持的 JPEG 和 HEIC/HEIF 文件，Motion Photo 会自动识别。

批处理同样支持 Motion Photo。

Swift CLI 还可以在 Motion Photo 转换时组合摄影风格功能。

### Python 实现

`xdremux-py` 现在是可安装的 Python 包。

它支持标准 HDR 转换、照片分类和 Motion Photo → Live Photo 转换。

Live Photo 实现运行时不依赖 Apple framework，因此可以在非 macOS 系统运行。

仓库会在 macOS 上使用 PhotoKit 测试 Python 生成的 Live Photo。

### 摄影风格

在支持的 macOS 系统上，摄影风格转换现在属于正常的 Swift CLI 产品路径。

实现会保留源 HDR 图片和 Gain Map，同时合成 Apple Photos 可消费的摄影风格元数据和辅助资源。

摄影风格求解器包括全局 tone curve 拟合、scene-aware 策略、semantic mattes，以及 Apple framework consumer 验证。

### 分类与归类

XDRemux 可以根据来源特征和主要拍摄模式分类支持的照片，也可以按照这些分类整理批处理结果。

### 稳定性

本版本加入更严格的结构验证、fail-closed 解析、原子发布、有限并发批处理、checkpoint/resume 和更多真实设备 fixture。

### 转向 Rust

v1.4 是现有 Swift 与 Python 产品实现的兼容发布版本。之后的开发线会用一个跨平台 Rust CLI 和一个 Rust 业务核心替代两套并行实现；Apple 独占 framework 能力仅保留在薄平台适配器之后。
