Injected `EOPNOTSUPP` proves safe failure with the original I/O error; it is not a mounted FAT/exFAT test, and those filesystems are not claimed supported. Two names are not one system-atomic transaction. No power-loss directory-entry guarantee or prevention of another writer's active replacement is claimed. These tradeoffs are explicit in both current architecture documents.
